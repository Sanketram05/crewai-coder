### Step 1: Plan How the Code Will Work

The given series is the Leibniz formula for $\pi$:
$$\pi = 4 \times \left(1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \dots\right)$$

To calculate the first 10,000 terms of this series in Python:
1. Initialize a variable `total` to `0.0` to keep the sum of the series.
2. Use a `for` loop that runs 10,000 times (from $i = 0$ to $9999$).
3. In each iteration, calculate the denominator as $2 \times i + 1$ (giving 1, 3, 5, 7, etc.).
4. Determine the sign of the term: even indices ($i = 0, 2, 4, \dots$) are positive, and odd indices ($i = 1, 3, 5, \dots$) are negative. This can be efficiently done using `(-1)**i`.
5. Add the term $\frac{(-1)^i}{2i + 1}$ to `total`.
6. After the loop finishes, multiply `total` by 4.
7. Print the final calculated value, which should be a close approximation of $\pi$.

---

### Step 2: Write the Python Code

```python
def calculate_leibniz_pi(n_terms=10000):
    total = 0.0
    for i in range(n_terms):
        denominator = 2 * i + 1
        term = 1 / denominator if i % 2 == 0 else -1 / denominator
        total += term

    pi_approximation = total * 4
    return pi_approximation


if __name__ == "__main__":
    n = 10000
    result = calculate_leibniz_pi(n)
    print(f"Result after multiplying the first {n} terms by 4: {result}")
```
